Design recorded before production edits. Extend existing capture, STT, playback,
wake gates, queue/command intake and release scripts. Do not replace them.

Reviewed speech must use CommandService, including server-owned capability gates,
durable clarification and request identity. Keep legacy reviewed note inputs as a
compatibility transport translated into that same command path. Add a general
editable command and explicit clarification confirmation. Neither transcript nor
voice confirmation can resolve Save approval. Summaries describe independently
verified final status without speaking private payloads. Cancel, Stop, stale
revision, review expiry and speech suppression remain fail-closed.

Extend evaluation to separate recognition from evidence of reviewed end-to-end
actions. Keep templates distinct from actual consented recordings. No corpus was
provided; the user does not have prepared model/corpus paths. Physical unplug,
speaker/echo and labelled spoken-command tests require a supervised human session.
Never substitute generated silence or adapter fixtures for those gates.

Preserve the existing package and its historical evidence. Build into a new
folder with a fresh build root; bind checksums to exact source and locks. Extend
package checks for current schema, command intake and voice defaults. Exercise
the actual preserved prior executable and candidate for isolated upgrade and
rollback; do not label a same-version rehearsal a release-pair pass. Fresh
standard-account qualification cannot be inferred from the developer account.

Inspect current reliability arguments and run a fresh final-source attempt with
normal resource safeguards. A short harness check or blocked preflight is not a
two-hour soak. Publish source, laptop, package and public-site evidence separately.
Custom wake, native Notepad, browser research, cloud/MCP and unqualified language
support retain their independent gates.

## Changes and verification boundaries

- `voice/service.py`, `voice/contracts.py`, `api/routes/voice.py`: legacy reviewed
  notes and general reviewed commands both enter CommandService. Clarification
  requires another current-session/revision confirmation. Review still expires;
  Stop/disconnect clears the ephemeral transcript and command snapshot. Speech
  never resolves Save authority. Only a persisted terminal, verified task can
  produce the generic success sentence; private payload text is not spoken.
- `tasks/commands.py`: voice provenance is server-owned, protected with intent
  data, and retained through clarification. The `voice-` request namespace is
  reserved; typed clients cannot assert it. Existing queue replay, ownership,
  permits, native/browser gates and graph/checkpoint budgets are reused.
- `VoicePanel.tsx`: editable supported commands, legacy note review and explicit
  missing-value forms. Refresh/polling recovers state without submitting work;
  uncertain transport relies on snapshots and stable server intake identity.
  Existing keyboard Stop, safe literal rendering and display-before-speech remain.
  A confirmed voice session identifies its original request; retries resolve that
  request. Start a fresh voice review to change the goal after confirmation. Stop
  cancels queued work; cancelling voice alone interrupts voice handling.
- `voice/evaluation.py`, `voice/action_evaluation.py`,
  [evaluation protocol](../../evaluation/voice/V3.6-protocol.md): recognition binds
  the private label-manifest hash. The separate read-only action evaluation checks
  a voice-origin intake, exact artifact bytes/hash, terminal verified task and
  matching ledger receipt. Unmeasured samples have null accuracy, not zero or
  fabricated passes. Use unique new destinations for each labelled action trial;
  placeholder filenames/references must be adjusted to the actual planned speech
  before recording. Recording-to-session pairing remains operator supplied.
- Build/self-test scripts: fresh output and work roots preserve old packages;
  the manifest binds exact source. Current-schema and frozen command/clarification
  checks extend the original package test. The new prior-artifact script uses both
  actual executables and separate upgrade/rollback roots. A helper-name collision
  with PowerShell's `cli` alias failed its first attempt; the helper was renamed
  and the original bundle's complete checksum inventory remained intact.
- `m7_soak.py`: optional normal-resource preflight and fail-fast interruption
  record a blocked/failed attempt without relaxing the original 7,200-second,
  >=100 verified task, >=2 backup/restore, <=20% warmed-parent-RSS growth and
  <0.5-second health-p95 passing gates. A shortened attempt cannot qualify.

No dependency upgrade, model download, cloud request, public-site operation,
autostart installation or global microphone/power-setting change was performed.
All runtime roots used here are fresh `.local/v36-*` test roots. Existing user
runtime data, previous test roots and `dist/windows/Victus` are preserved.
