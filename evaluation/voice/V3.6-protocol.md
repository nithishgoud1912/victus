# Reviewed voice qualification

The existing template contains labels only: **no recorded test corpus exists**.
The discovered local English model is a prerequisite, not recognition evidence.
Do not use silence, library sample WAVs, synthetic speech or unpaired typed tasks
as the requested 50 quiet / 50 noisy real-user command results.

1. Use an isolated runtime, the existing English model and explicit push to talk.
   Speak the labelled command, then edit and confirm its transcript in the
   dashboard. Missing details use the same saved command clarification as typed
   input. Keep private audio and reference text outside Git. Pair each opaque
   recording ID with the displayed saved command ID; do not reuse one task for
   multiple samples. Save approval is always a separate exact-action review.
2. Record 50 quiet and 50 noisy samples with predeclared labels and documented
   acoustic conditions, plus the existing negative categories. Recognition WER,
   intent and exact-target scores come from `victus.voice.evaluation`; its report
   binds the exact label manifest hash and never submits tasks.
3. End-to-end correct actions use `victus.voice.action_evaluation`, a separate
   read-only check. Supply the same private manifest, an ID-to-command-ID JSON
   object and the isolated runtime. It verifies the server-owned voice request
   namespace, successful task, exact expected bytes/hash and matching verified
   ledger receipt. The operator pairs recordings to reviewed sessions; the
   report does not claim independent proof of that human pairing. Missing cases
   remain unmeasured. The current corpus is deliberately bounded to English
   note commands; other intents/languages need corresponding labels/verifiers.
4. Perform a witnessed physical microphone unplug/reconnect, Stop during real
   STT/review/playback, audible mute/interrupt and real speaker echo test.
   Software flags and a successful SAPI call do not establish acoustic echo
   suppression or audibility. Record pass/fail observations without private audio.

```powershell
backend/.venv/Scripts/python.exe -m victus.voice.evaluation --manifest C:/private-voice/manifest.json --model C:/local-models/faster-whisper-base.en --output .local/v36-recognition-new.json
backend/.venv/Scripts/python.exe -m victus.voice.action_evaluation --manifest C:/private-voice/manifest.json --bindings C:/private-voice/reviewed-command-ids.json --data-dir C:/private-voice/runtime --output .local/v36-actions-new.json
```

No Hindi/mixed-language qualification is asserted. Wake assets and corpus gates
remain separate; wake detection cannot confirm a transcript or approve Save.
